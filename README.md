# 🎲 คลังบอร์ดเกม

เกมเล่นกับเพื่อนแบบนั่งล้อมวง พร้อมเสียงพากย์ภาษาไทย + อังกฤษ

- **มนุษย์หมาป่า (Werewolf)** — 32 บทบาท, พากย์กลางวัน–กลางคืนอัตโนมัติ, ไม่ต้องมีคนคุมเกม
- **คำต้องห้าม (Forbidden Words)** — ทุกคนเห็นคำต้องห้ามของเพื่อนแต่ไม่รู้คำตัวเอง หลอกให้เพื่อนพูดออกมา แล้วกด 🚨 จับ!
  มี 4 หมวดคำ (แก้/เพิ่มคำได้ที่ `games/forbidden/words.js`), โหมดตกรอบ หรือนับแต้ม
- **หนูขโมยชีส (Cheese Thief)** — ทุกคนตื่นตามเลขลูกเต๋า (ตี 1–6) ใครตื่นพร้อมหัวขโมยจะเห็นมันขโมยชีส
  ตื่นคนเดียวแอบดูลูกเต๋าคนอื่นได้ 6 คนขึ้นไปมีผู้สมรู้ร่วมคิด ตอนเช้าโหวตหาตัวคนร้าย พร้อมเสียงพากย์ไทย/อังกฤษ

## โครงสร้าง

| ที่อยู่ | คืออะไร |
|---|---|
| `assets/net-cloud.js` | ระบบห้องออนไลน์ผ่าน Supabase Realtime + เข้ารหัสข้อมูลแต่ละคน (ใช้ร่วมทุกเกม) |
| `assets/net-local.js` | ระบบห้องผ่าน `server.py` บนเครื่อง |
| `assets/party.css` | ปุ่ม แผง หน้าห้อง ที่ใช้ร่วมกัน |
| `assets/voice.js`, `assets/narration.js` | เครื่องเล่นเสียงพากย์ และการพากย์ตามบนมือถือผู้เล่น |
| `games/<เกม>/` | หน้าคนสร้างห้อง (`index.html`) และหน้ามือถือผู้เล่น (`play.html`) |

## วิธีเล่น 3 แบบ

| แบบ | ต้องใช้ | เหมาะกับ |
|---|---|---|
| 📱 เครื่องเดียว | เปิดหน้าเว็บอย่างเดียว | ส่งเครื่องเวียนกันในวง |
| 📲 หลายเครื่อง (ออนไลน์) | Vercel + Supabase (ฟรี) | ทุกคนใช้มือถือตัวเอง ไม่ต้องมีจอกลาง เล่นจากเครือข่ายไหนก็ได้ |
| 📲 หลายเครื่อง (ในบ้าน) | `python3 server.py` บนคอม | ทุกคนต่อ Wi-Fi เดียวกัน, พากย์ชื่อผู้เล่นด้วยเสียง Mac ได้ |

## ขึ้นเว็บด้วย Vercel + Supabase (เล่นออนไลน์ ไม่ต้องเปิดคอมทิ้งไว้)

### 1. สร้างโปรเจกต์ Supabase (ฟรี)
1. สมัครที่ <https://supabase.com> แล้วกด **New project** (ตั้งชื่ออะไรก็ได้ เลือก region ใกล้ไทย เช่น Singapore)
2. ไปที่ **Project Settings › API** (หรือ **API Keys**) แล้วคัดลอก
   - **Project URL** เช่น `https://abcdefgh.supabase.co`
   - **anon / publishable key**
3. ไปที่ **Realtime › Settings** ตรวจว่าเปิด **Allow public access** ไว้ (ค่าเริ่มต้นเปิดอยู่แล้ว)

> ไม่ต้องสร้างตารางหรือฐานข้อมูลใด ๆ — เกมใช้แค่ Realtime ส่งข้อความระหว่างเครื่อง

### 2. ใส่ค่าลงในเกม
แก้ไฟล์ [`assets/config.js`](assets/config.js):

```js
window.WW_CONFIG = {
  supabaseUrl: 'https://abcdefgh.supabase.co',
  supabaseAnonKey: 'คีย์ anon ที่คัดลอกมา',
};
```

คีย์ anon ออกแบบมาให้อยู่ในหน้าเว็บได้ (ไม่ใช่รหัสลับ) — **อย่าใส่ `service_role` key เด็ดขาด**

### 3. ขึ้น Vercel
วิธีที่ง่ายที่สุด (ต้องมี Node.js):

```bash
npx vercel --prod
```

ครั้งแรกจะให้ล็อกอินและถามค่าโปรเจกต์ — กด Enter ใช้ค่าเริ่มต้นได้ทั้งหมด
(ไม่ต้องมี build command — เป็นเว็บไฟล์ธรรมดา)

หรือจะ push โฟลเดอร์นี้ขึ้น GitHub แล้วกด **Import** ที่ <https://vercel.com/new> ก็ได้ (Framework Preset: **Other**)

### 4. เล่น
1. เปิดลิงก์ Vercel บนมือถือของ "เจ้าห้อง" › มนุษย์หมาป่า › **📲 หลายเครื่อง**
2. ติ๊ก **🙋 ฉันเล่นด้วยบนเครื่องนี้** แล้วใส่ชื่อ — เครื่องนี้จะพากย์เสียงและเป็นผู้เล่นไปพร้อมกัน (ไม่ต้องมีจอกลาง)
3. เพื่อนสแกน QR หรือเปิดลิงก์แล้วใส่ชื่อ
4. เลือกบทบาท แล้วกดเริ่มเกม

**ความเป็นส่วนตัว:** บทบาทและผลการตรวจของแต่ละคนถูกเข้ารหัส (ECDH + AES-GCM)
ด้วยกุญแจที่มีแค่เจ้าห้องกับผู้เล่นคนนั้น คนอื่นที่ฟังห้องเดียวกันจะอ่านไม่ออก

**ข้อจำกัด:** บน Vercel ไม่มีเสียง Mac — ชื่อผู้เล่นจะพากย์ด้วยเสียงของเบราว์เซอร์
(ถ้าเบราว์เซอร์ไม่มีเสียงไทย ชื่อจะแสดงเป็นตัวหนังสือ) บทพากย์อื่น 421 ประโยคอัดไว้แล้ว เล่นได้ปกติ

## เล่นบนเครื่อง (ไม่ใช้ Supabase)

ปล่อย `assets/config.js` ว่างไว้ แล้วรัน

```bash
python3 server.py            # มือถือต้องต่อ Wi-Fi เดียวกัน
python3 server.py --public   # เปิดลิงก์สาธารณะ (ต้องติดตั้ง cloudflared ก่อน)
```

แล้วเปิด <http://localhost:8765>

## แก้ไขบทพากย์

บทพากย์อยู่ใน `games/werewolf/roles.js` และ `games/werewolf/lines.js` (มีคำแปลอังกฤษด้วย)
(เกมหนูขโมยชีส: `games/cheese/lines.js`) แก้แล้วอัดเสียงใหม่บน Mac:

```bash
python3 tools/build_voice.py            # ทุกเกม
python3 tools/build_voice.py cheese     # เฉพาะเกมเดียว
```

## ทดสอบโหมดออนไลน์โดยไม่ต้องมี Supabase

ตั้ง `supabaseUrl: 'mock'` และ `supabaseAnonKey: 'mock'` ใน `assets/config.js`
แล้วเปิดหลายแท็บในเบราว์เซอร์เดียวกัน — แท็บจะคุยกันเองผ่าน `dev-supabase-mock.js`
(อย่าลืมเปลี่ยนกลับก่อนขึ้นเว็บจริง)
